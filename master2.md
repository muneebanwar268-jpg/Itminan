# CORE PHILOSOPHY

We are NOT building sections.

We are directing scenes.

Think like a Film Director.

NOT like a Web Designer.

The website should feel like a luxury documentary.

Each scroll should reveal another scene.

The visitor should never notice where one section ends and another begins.

Instead they should simply continue discovering the product.

================================================================================

# STORY STRUCTURE

Our story consists of chapters.

Chapter 1

Attention

↓

Chapter 2

Curiosity

↓

Chapter 3

Desire

↓

Chapter 4

Understanding

↓

Chapter 5

Trust

↓

Chapter 6

Purchase

Every chapter should naturally transition into the next.

Never use hard visual breaks unless absolutely necessary.

================================================================================

# SCROLL PHILOSOPHY

Scrolling is not navigation.

Scrolling is storytelling.

The user's mouse wheel or finger controls the pace of the story.

Animations should never feel disconnected.

The scroll itself becomes the timeline.

Think:

Apple Product Pages

Nothing

Dyson

Bang & Olufsen

================================================================================

# GSAP PHILOSOPHY

GSAP is not decoration.

GSAP is storytelling.

Every timeline must answer:

Why does this animation exist?

If it has no purpose—

Remove it.

================================================================================

# GSAP RULES

Always prefer timelines.

Avoid isolated animations.

Group related animations into one sequence.

Use ScrollTrigger only where storytelling benefits.

Avoid creating hundreds of triggers.

Use scrub only when it improves the experience.

Never over-pin every section.

Pin only signature chapters.

================================================================================

# SCROLLTRIGGER STRATEGY

Use ScrollTrigger for:

Hero

Feature Showcase

Product Detail Reveal

Image Sequence

Lifestyle Story

CTA Reveal

Avoid pinning:

Footer

FAQ

Simple content sections

Long forms

================================================================================

# LENIS

Lenis controls the scrolling experience.

It should feel:

Smooth

Natural

Responsive

Never floaty.

Never delayed.

Scrolling should still feel connected to user input.

================================================================================

# HERO PHILOSOPHY

The Hero is NOT a banner.

The Hero is the opening scene of the film.

When the page loads the visitor should stop scrolling for a moment.

They should simply admire the product.

# MOTION TIMING

150–250ms

================================================================================

# QUALITY CHECK

Before shipping any section ask:

Does the motion improve understanding?

Does it feel expensive?

Is anything unnecessary?

Is performance still excellent?

Does this feel handcrafted?

Would Apple approve this motion?

If not—

Improve it.

================================================================================

# GOLDEN RULE

Motion should disappear.

The visitor should remember the experience—

not the animation.

If users notice the animation more than the product,

the motion has failed.
